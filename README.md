Store Sales Analysis & Forecasting Dashboard

Overview
This project presents an interactive Store Sales Analysis Dashboard developed using Microsoft Power BI. It provides insights into sales performance, profitability, customer segments, product categories, shipping methods, and regional sales distribution.
The dashboard includes interactive region-based filtering across four regions: Central, East, South, and West. It also features a 15-day sales forecasting report to explore future sales trends based on historical data.

Dashboard Pages
1. Store Sales Insights Dashboard
This page provides an overview of store sales performance through interactive visualizations and key performance indicators.

Key Performance Indicators
- Total Sales
- Total Orders
- Total Profit
- Average Shipping Days
The KPI values dynamically update based on the selected region.

Analysis Includes
- Sales distribution by customer segment.
- Sales distribution by payment mode.
- Monthly sales comparison for 2019 and 2020.
- Monthly profit comparison for 2019 and 2020.
- Sales performance by shipping mode.
- Sales analysis by product category and subcategory.
- State-wise sales and profit distribution.
- Interactive filtering across Central, East, South, and West regions.

2. Store Sales Forecast Dashboard
This page focuses on historical sales trends and future sales predictions.
Key Features
- 15-day sales forecasting.
- Historical sales trend visualization.
- Forecast confidence interval visualization.
- State-wise sales comparison.
- Date range selection for exploring sales trends.

Technologies Used
Microsoft Power BI: Dashboard development and data visualization.
Power Query: Data cleaning and transformation.
DAX: Calculated measures and data analysis.

How to Run
1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Sales_Analysis_Dashboard.pbix`.
4. Navigate through the report pages.
5. Use the available region filters and other interactive elements to explore the sales data.
